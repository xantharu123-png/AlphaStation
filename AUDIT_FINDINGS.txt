DISCREPANCY #1: RVOL Gate Disables Smart Money Signals on Real Breakouts
--------------------------------------------------------------------------
Code: Line 835 (sm_eligible check) + Lines 1761-1766 (reset counters)

Problem: Case B has legitimate breakout setup:
  - avg_volume = 1.45M (> 100K threshold)
  - Recent vol = 1.08M (includes the 3M spike on last bar)
  - But 5-bar average recent vol / total avg vol = 0.75 < 0.8
  - Result: sm_eligible = False → sm_fires = 0, sm_hits = 0

Evidence:
  - OBV signal at line 996 prints: "OBV-Divergenz bullisch [Smart Money!]"
  - Code increments sm_fires += 1 and sm_hits += 1 at line 996
  - But in output: sm_fires=0, sm_hits=0
  - This is because line 1765 RESETS them: "smart_money_fires = 0"

Why Wrong:
  - Volume drying up (RVOL 0.75) is the CLASSIC breakout setup (Wyckoff)
  - Threshold 0.8 is too strict; should be 0.65-0.70
  - Penalizes setups that have vol contraction (which is the whole point!)

Impact:
  - Case B: Score 70 is Valid but Grade D (needs sm_hits >= 2 for Grade B)
  - Grade is stuck at D even with all bullish signals
  - Breaks the grading system (Grade B requires Smart Money confirmation)

Fix: Lower RVOL threshold to 0.65, or use different recent_vol calculation


DISCREPANCY #2: ADX > 20 Returns 0 Points (Blocks Healthy Uptrends)
-------------------------------------------------------------------
Code: Lines 1154-1167 (Signal 7: ADX Turning)

Problem: Case D has ADX=100 (strong uptrend)
  - Signal 7 logic: if adx < 20 → 4-14 points; else → 0 points
  - ADX > 20 means "trend already established" → prints "Trend running" → no points

Evidence:
  - Case D: ADX=100, signal says "ADX bereits hoch (Trend laeuft schon)" (0pts)
  - But uptrend IS valid; ADX high = bullish not bearish

Why Wrong:
  - Confuses "ADX low turning up" (new trend) with "ADX high" (trend established)
  - Healthy consolidations within established uptrends have ADX > 20
  - Missing 14pts of BOOSTED signal = no Grade B possible
  - Case D needs those 14pts to reach threshold

Fix: Add separate logic for "ADX > 20 AND consolidating range" as bullish continuation


DISCREPANCY #3: price_flat Gate (< 5%) Demotes OBV Signal
-----------------------------------------------------------
Code: Lines 924-926 (price_flat check)

Problem: Case D moves +5.6%, so price_flat=False
  - OBV Divergence (Signal 3): +13pts if price_flat, only +7pts if not
  - Case D: OBV is rising, price is rising, but < +8% move
  - Signal 3 at line 1009: "OBV steigt (Preis nicht flat)" = +7 only

Evidence:
  - Case D: price_change_pct = +5.61% (> 5%) → price_flat = False
  - OBV award: +7pts instead of +13pts BOOSTED
  - Missing 6pts

Why Wrong:
  - +5.6% move over 30 bars is SLOW (0.19%/day)
  - OBV rising in slow uptrend is still bullish
  - Threshold too strict; should be 8-10%

Fix: Raise price_flat threshold to 8% or make it directional


DISCREPANCY #4: Resilience Broken for Pure Uptrends
----------------------------------------------------
Code: Lines 1311-1334 (Signal 11: Relative Strength)

Problem: Case D has 0 down days (pure uptrend)
  - negative_days = 0
  - resilience = recovery_days / max(1, negative_days) = 0/1 = 0%
  - Signal 11: resilience 0% → 0 points

Evidence:
  - Case D: [100% Higher Lows] but [0% Resilience] (contradictory)
  - negative_days = 0 treated as "no resilience" instead of "perfect hold"

Why Wrong:
  - Stock with 0 down days IS perfectly resilient
  - Should award max 14pts, not 0pts
  - Missing 14pts critical for reaching Grade B/threshold

Fix: Handle negative_days=0 case: award 14pts immediately (100% hold strength)

SUMMARY
================================================================================

The function is OVERFITTED to "extreme" breakout patterns:
  - Flat price with rising volume (OBV divergence)
  - ADX < 20 turning up (trend initiation)
  - Frequent down days with quick recovery (resilience signal)

These are RARE. It underscores NORMAL consolidations:
  - Healthy uptrend consolidations
  - Volume contraction before breakout (Wyckoff dry-up)
  - Pure uptrends (no down days)

MOST CRITICAL ISSUES (ranked by impact):
  1. RVOL 0.8 threshold (blocks vol dry-up setups) - HIGH
  2. ADX > 20 returns 0 (blocks established trends) - HIGH
  3. Resilience formula (0 down days = 0%) - MEDIUM
  4. price_flat 5% threshold (demotes OBV signal) - MEDIUM

RECOMMENDED ACTION:
  - Lower RVOL from 0.8 to 0.65-0.70
  - Restructure ADX signal to reward high ADX in consolidation
  - Fix resilience: negative_days=0 → award 14pts (perfect hold)
  - Raise price_flat to 8% OR make it direction-aware
